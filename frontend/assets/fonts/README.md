# Polices de caractères

Ce dossier contient les polices utilisées par l'application COMPTAB POS.

## Polices requises :
- `Roboto-Regular.ttf` - Police normale
- `Roboto-Medium.ttf` - Police moyenne (weight: 500)
- `Roboto-Bold.ttf` - Police en gras (weight: 700)

## Téléchargement :
Vous pouvez télécharger les polices Roboto depuis Google Fonts :
https://fonts.google.com/specimen/Roboto

## Alternative :
Si vous n'avez pas les polices Roboto, l'application utilisera la police système par défaut.
