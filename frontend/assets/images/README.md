# Images

Ce dossier contient les images utilisées par l'application COMPTAB POS.

## Images requises :
- Logo de l'application
- Icônes personnalisées
- Images de produits (si applicable)

## Format recommandé :
- PNG ou SVG pour les icônes et logos
- JPG pour les images de produits
- Taille optimisée pour le web

## Structure suggérée :
- `logo/` - Logos de l'application
- `icons/` - Icônes personnalisées
- `products/` - Images de produits
- `ui/` - Éléments d'interface
