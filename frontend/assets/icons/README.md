# Icônes

Ce dossier contient les icônes SVG utilisées par l'application COMPTAB POS.

## Icônes requises :
- Icônes de navigation
- Icônes d'actions
- Icônes de statut

## Format recommandé :
- SVG pour une meilleure qualité
- Taille standardisée (24x24, 32x32)
- Couleurs configurables via CSS

## Structure suggérée :
- `navigation/` - Icônes de navigation
- `actions/` - Icônes d'actions (ajouter, modifier, supprimer)
- `status/` - Icônes de statut (actif, inactif, en attente)
- `categories/` - Icônes de catégories de produits
